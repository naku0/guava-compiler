# guava compiler

Учебный проект компилятора/интерпретатора на Scala 3. Проект разбирает небольшой язык с расширением `.guava`: лексер превращает исходный код в токены, парсер строит AST, семантический анализатор проверяет типы и области видимости, а runtime-слой постепенно развивается в интерпретатор.

## Стек

- Scala 3.7.3
- sbt

## Быстрый старт

Скомпилировать проект:

```bash
sbt compile
```

Запустить файл по умолчанию:

```bash
sbt "run"
```

Если рядом есть `data.guava`, будет прочитан он. Иначе используется старый файл `data`.

Запустить конкретный файл:

```bash
sbt "run generated.guava"
sbt "run --file data.guava"
```

Сгенерировать случайную `.guava` программу:

```bash
sbt "run --generate generated.guava 20"
```

Где `20` - количество верхнеуровневых инструкций. Если число не указать, будет использовано значение по умолчанию.

Показать справку:

```bash
sbt "run --help"
```

## Пример `.guava`

```guava
var x = 10;
var words = ["guava", "scala", "compiler"];
var nums = [1, 2, 3];

print words[0];
nums[1] = x + 32;
print nums;
```

## Что поддерживается

Лексер:

- числа;
- строки;
- идентификаторы;
- ключевые слова: `var`, `val`, `def`, `print`, `if`, `else`, `while`, `return`, `break`, `continue`;
- операторы: `+`, `-`, `*`, `/`, `=`, `==`, `!=`, `<`, `>`, `<=`, `>=`, `!`, `&&`, `||`;
- скобки: `()`, `{}`, `[]`;
- `;` и `,`.

Парсер и AST:

- объявления `var`;
- выражения;
- присваивание;
- `print`;
- блоки;
- `if/else`;
- `while`;
- числовые и строковые выражения;
- бинарные и унарные операции;
- массивы: `[1, 2, 3]`;
- обращение по индексу: `arr[0]`;
- присваивание по индексу: `arr[1] = 42`;
- функции: `def name(arg1, arg2) { ... }`;
- вызовы функций: `name(1, 2)`;
- `return`;
- AST-заготовки для lambda/block/if expressions.

Семантический анализатор:

- проверяет необъявленные переменные;
- проверяет использование неинициализированных переменных;
- ловит повторные объявления в одной области видимости;
- проверяет типы арифметических, логических операторов и сравнений;
- предупреждает о сравнении разных типов;
- предупреждает о неиспользуемых переменных;
- частично ловит недостижимый код для очевидно ложных условий;
- проверяет, что элементы массива одного типа;
- проверяет, что индекс массива имеет тип `Number`;
- проверяет тип значения при записи в массив.

Runtime/interpreter-слой:

- есть `RuntimeEnvironment`;
- есть `TreeInterpreter`;
- поддержаны runtime-значения переменных, блоки, `if`, `while`, функции, `return`, массивы и проверки границ массива;
- текущий `main` пока запускает front-end pipeline и печатает AST, а не выполняет программу через интерпретатор.

## Структура проекта

```text
src/main/scala
├── generator/          # генератор случайных .guava программ
├── interpreter/        # runtime environment и tree interpreter
├── lexer/              # токены, lexer, keyword/operator maps
├── parser/             # parser и AST
├── semantic/           # типы, symbol info, semantic analyzer
├── Reader.scala        # чтение исходных файлов
└── main.scala          # CLI entrypoint
```

## Генератор программ

`RandomProgramGenerator` создаёт `.guava` код на основе поддерживаемых токенов и конструкций языка. Он генерирует:

- переменные;
- числа и строки;
- массивы чисел и строк;
- присваивания;
- индексные присваивания;
- `print`;
- `if/else`;
- `while`;
- арифметические, логические выражения и сравнения.

Пример:

```bash
sbt "run --generate generated.guava 10"
sbt "run --file generated.guava"
```

## Текущее поведение `main`

При запуске файла проект:

1. читает исходный код;
2. токенизирует его;
3. парсит в AST;
4. запускает семантический анализ;
5. печатает errors/warnings;
6. если semantic errors нет, печатает AST.
